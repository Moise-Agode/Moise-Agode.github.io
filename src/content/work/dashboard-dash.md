## Présentation

Ce projet est une application web simple développée avec **Dash**, le framework Python de Plotly destiné à la création d’interfaces analytiques interactives.

L’application présente un graphique en barres comportant deux séries de données. Elle illustre la création d’une mise en page Dash et l’intégration d’une visualisation dans une application web Python.
